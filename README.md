# boltscope

Bolt encode/decode helpers for scope payloads in pipelines.

**Site:** https://theworker02.github.io/boltscope/

## Install / run

```bash
git clone https://github.com/theworker02/boltscope.git
cd boltscope
node src/cli.js
node --test
```
